Lines to export

Localization and option-code lines such as P52534-B21 ABA are never exported. OCA's JSON has no place for them.

OCA header

Defaults come from your OCA exports. Solution type is a guess for combined files: OCA writes Single for one server, and the value for several is unconfirmed. If Power Advisor rejects a combined file, switch it and save again. Changes are remembered in this browser.
